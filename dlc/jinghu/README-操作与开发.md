# 京沪高铁 DLC 操作与开发说明

## 启动
打开根目录 `上海地铁模拟驾驶.html`（离线单文件），主菜单点「高铁 DLC · 主场景 G25」。
不会弹窗，直接进主场景驾驶室。

## 驾驶操作
- `W` / 牵引：加速
- `S` / 制动：常用制动
- `空格` / 紧急制动：-2.5 m/s²
- `P`：受电弓升/降（降弓自动分 VCB）
- `V`：VCB 合/分（受电弓未升时不允许合）
- `H`：鸣笛
- 停站后点「发车」：关门后进入下一段；门未关不能走车
- `C` / 视角按钮：驾驶室 ↔ 前左 ↔ 车尾
- 拖拽画面：驾驶室环视；「回正视角」/`R` 回正
- `Esc`：退出主场景
- HUD 右上「收起/展开」：隐藏/显示状态行；状态会记住

## 主场景状态
- 北京南起点 0 km/h 待发；停站：南京南、上海虹桥。
- 四屏 DMI：仪表/25kV、G25 模式、下一站、速度/ATP。
- 车门灯、受电弓/VCB、ATP 超速制动、停车对标、终到结算。
- HUD：计划/实际、正晚点、信号、ETA、制动/进站提示。

## 构建与测试
```bash
cd shanghai-metro
npm run build          # 正式版
npm run build:readable # 可读版
npm run smoke          # 冒烟
npm test               # 全量（含 HSR 回归）
npm run test:hsr       # 仅京沪高铁
```

## 已知差距
- 车头 v011 是 v009 倒角+平滑，不是 CR400AF-BS 1:1；鼻锥未重新放样。
- 驾驶室是程序化几何，不是 1:1；座椅/侧台/开关为简化体块。
- 站台/站房是块模。
- 音频是合成音；信号无真正进路逻辑。
- 当前 HSR 停站只有南京南、上海虹桥；北京南是起点。
